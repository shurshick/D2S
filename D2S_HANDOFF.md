# D2S 0.3: текущее состояние

Репозиторий: https://github.com/shurshick/D2S

Полное пространство имён D2S, чистая установка в /opt/d2s, без миграции. Служба S99d2s. Старые исходники и исходные handoff доступны в archive/d2s-0.2.0.

Только стенд 192.168.31.1. Основной роутер не использовать. keenetic-doq на стенде сохранять. Источник требований — D2S_SPEC.md и текущие указания пользователя. Происхождение — NOTICE.md.

05.11: первый этап ускорения опубликован как stable/latest d2s-v0.3.1,
commit a58fc2812ea5ff1d6d999178ac9b06718c0cc581. На ARM64 пройдены штатное
подписанное обновление и минутная проверка здоровья. AUTOUPDATE возвращён
в 1, диагностика — в исходное выключенное состояние. Полная регрессия
core/datapath/detect и проверки GitHub прошли.
Свидетельства: [docs/field/2026-11-05-performance-stage1.md](docs/field/2026-11-05-performance-stage1.md).
Владелец подтвердил YouTube, приложение Telegram и WhatsApp при выключенном
обходе вышестоящего шлюза. Это не приёмка Telegram Web: его загрузка отдельной
задачей исследуется после сообщения владельца о ERR_CONNECTION_RESET.
Перед новым полевым опытом заново проверить текущую установку стенда.

05.11, продолжение: в main перенесены статусы
Telegram из t0fox/d2o `1cc424e` в оформление D2S и скрывает только записи
с явным пустым `bindings`, сохраняя планы. Неполные данные показываются
как «цели не получены», ссылки семейств и счётчики обновляются вместе.
Проверки панели, Telegram и полный браузерный сценарий прошли; раскладка
проверена на 16 ширинах 320–1920 px. После окончательного переименования
двух JS API дополнительно проверены загрузка и работа схемы через Playwright.
Подробности: [docs/field/2026-11-05-telegram-panel.md](docs/field/2026-11-05-telegram-panel.md).

Опубликован prerelease `d2s-v0.3.2-test1`, исходник `1b4a36d`; точные проверки
GitHub и выпуск 42013737270 прошли. Архивы трёх архитектур скачаны обратно,
подпись, суммы и UI проверены. Stable/latest остаётся 0.3.1.

Владелец разрешил заменить оригинальный d2o на стенде с резервной копией.
Выполнена чистая установка 0.3.2-test1 на 192.168.31.1. Копия d2o, его
настроек и откат — `/opt/d2s-panel-backup-20261105-1`, права 0700. Копия
архива есть также в закрытых локальных файлах. В 14:01 все службы и
правила исправны, keenetic-doq жив и не изменён, панель в Chrome без ошибок.
AUTOUPDATE=0 временно для теста, чтобы stable0.3.1 не заменила prerelease.

«Коробка 13» оказалась на основном роутере: read-only GET подтвердил
явный пустой bindings, один план и ноль примет. Подсчёт верен, новая панель
скрывает эту запись без удаления плана. На основном роутере ничего не
изменяли, сетевых опытов не было. Его обход сейчас включён (MODE=apply),
поэтому владелец получил вопрос выключить именно верхний обход и проверить
YouTube/Telegram/WhatsApp через стенд. Ответ пока ожидается.

Telegram Web всё ещё отдельная неисправность; сетевой патч не включён,
успех Web не заявляется. Статический разбор: HTTPS попадает в MTProto redirect,
а планировщик исключает telegram.org по старому предположению о VPS-туннеле.
Следующая работа — протокольное разделение HTTPS/MTProto с регрессиями и
проверкой без вышестоящего обхода, сохранив работу приложения Telegram.
