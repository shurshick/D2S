# D2S 0.3: текущее состояние

Репозиторий: https://github.com/shurshick/D2S

Полное пространство имён D2S, чистая установка в /opt/d2s, без миграции. Служба S99d2s. Старые исходники и исходные handoff доступны в archive/d2s-0.2.0.

Только стенд 192.168.31.1. Основной роутер не использовать. keenetic-doq на стенде сохранять. Источник требований — D2S_SPEC.md и текущие указания пользователя. Происхождение — NOTICE.md.

commit ebf77be. На стенде d2s-v0.3.1-test1, ARM64; публичный стабильный 0.3.0
не заменён. Полная локальная регрессия core/datapath/detect прошла.
Свидетельства: [docs/field/2026-11-05-performance-stage1.md](docs/field/2026-11-05-performance-stage1.md).
