# Начальная TCP-база: стенд, 6 ноября 2026

Проверялся только стенд 192.168.31.1 (ARM64), без обращения к основному роутеру.
Владелец подтвердил прежнюю схему: интернет через стенд, верхний обход и
отдельный верхний Telegram-туннель выключены. keenetic-doq оставлен работающим.

## Методика

Один диагностический ARM64-бинарник выполняет три обычных TCP/TLS-пробы
последовательно либо одновременно. Для каждого имени адрес разрешается один
раз, порядок режимов — ABBA (serial, parallel, parallel, serial). ClientHello,
SNI, адрес, метка 0x2f, три повтора и сроки по 6000 мс сохранены. Диагностика
останавливается после базового наблюдения: обход и полный поиск не запускаются.
Контрольные суммы конфигурации D2S и init/config DoQ до/после совпали.

Первый опыт 11:33–11:35 MSK, установленная версия 0.3.3:

| Цель | Адрес | Последовательно, мс | Одновременно, мс | Исход каждой тройки |
| --- | --- | --- | --- | --- |
| github.com | 140.82.121.3 | 481; 443 | 172; 153 | 3 успеха, 0 ошибок |
| i.ytimg.com | 142.251.144.6 | 18232; 18218 | 6071; 6069 | 3 отрицательных, 0 ошибок |
| yt3.ggpht.com | 192.178.183.132 | 18241; 18255 | 6081; 6091 | 3 отрицательных, 0 ошибок |

Все 12 запусков выполнили ровно по три соединения. Медиана отрицательных
вопросов — 18236,5 → 6076 мс (примерно втрое быстрее именно этот вопрос).
Прямой GitHub не стал ошибочно отрицательным. Это небольшая выборка одного
канала, не гарантия того же выигрыша на другом провайдере.

На длинных отрицательных запусках `/proc/PID/status` через секунду показывал
один против трёх потоков, RSS 544–548 против 576–584 КиБ. Максимальный RSS
из getrusage — до 928 КиБ в обоих режимах. Виртуальная область данных выросла
с 140 до 16548 КиБ из-за резервов стеков pthread; это не 16 МиБ занятой RAM,
но дополнительная адресная область и потоки всё равно являются расходом.
На слабых/32-битных устройствах за этим нужно следить. Отказ pthread имеет
последовательный запасной путь. Измерение CPU на этом ядре вернуло 0 мкс;
выводов о снижении CPU по нему делать нельзя.

Этот первый опыт проведён до финального изменения места проверки отмены;
его результаты нельзя выдавать за замер точного опубликованного коммита.

## Кандидат и приложения

В 11:48 MSK на стенд установлен подписанный `0.3.4-test1` из `510cbc0`.
До установки сохранены код, настройки, состояние и сценарий восстановления;
копия архивов дополнительно проверена на ПК. Контроллер, датапат, панель,
Telegram, резолвер и DNS-наблюдатель работают; PPE8/8 IPv4+IPv6 и очередь2000
исправны. Диагностика выключена, DoQ жив и его контрольные суммы совпадают.
Автообновление временно выключено до перехода на стабильный выпуск.

Владелец подтвердил новое видео YouTube с перемоткой и отправку файла
в Telegram/WhatsApp на кандидате с выключенным верхним обходом.
Это пользовательская приёмка этих действий, не проверка звонков/Telegram Web.
Полный Linux detect check, ASan/UBSan и TSan прошли. На WSL запуск TSan
с обычной рандомизацией адресов завершался ошибкой среды unexpected memory
mapping; проверка прошла через `setarch x86_64 -R`, без изменения системных
настроек. Новые тесты с реальными сокетами дополнительно прошли под QEMU
для ARM64, ARMv7 и MIPSel.

Полные локальные `make -C core check`, `make -C datapath check` и
`make -C detect check` завершились успешно. Для места под штатное обновление
полная промежуточная резервная копия перенесена на ПК после проверки внешнего
хеша, обоих вложенных архивов и всех элементов. Исходная копия d2o на роутере
сохранена; пути восстановления указаны в D2S_HANDOFF.md.

В журнале установленного контроллера после 11:48 дополнительно найдено
9 TCP-поисков по собственному плану с четырьмя пробами (три базовых и проверка).
Их `classify_ms`: 6089, 6087, 6085, 6086, 6083, 6087, 8258, 6082, 6084;
медиана 6086 мс. Полное время этих поисков — 7654–20098 мс: остальные фазы
по-прежнему стоят времени. Это наблюдение работы кандидата, не парное
сравнение всего поиска с предыдущей версией.

В 11:54–11:55 контроллер имел RSS 9376–9652 КиБ (HWM11788), число его потоков
менялось 2 → 5 → 3. PID всех служб оставались прежними. Доступная память
64332–65092 КиБ, DoQ исправен. Это выборочные отсчёты при реальном трафике,
не измерение худшего случая для всех моделей роутеров.

Полный GitHub [CI42189995661](https://github.com/shurshick/D2S/actions/runs/42189995661)
для `510cbc08c81a09fdcf7eb88c94b4729380d6eec7` завершён успешно:

## Чего опыт не доказывает

- Ускорение свойств, проверки планов или всего запасного перебора.
- Работоспособность приложений после обновления движка: она требует отдельного
  пользовательского теста кандидата.
- Работоспособность Telegram Web, звонков или любого непроверенного протокола.
- Отсутствие влияния одновременных соединений на любых ограничителях частоты.
