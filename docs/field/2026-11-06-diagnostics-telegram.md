# Диагностика и Telegram: стенд, 06.11.2026

Кандидат `0.3.5-test1`, source `1f2e55c6d44671c207035522a02f8dcd1e3d816a`,
установлен на ARM64-стенд 192.168.31.1 в 13:59 МСК с сохранением настроек,
каталога и регистрации Telegram. Перед этим проверена отдельная резервная
копия D2S 0.3.4 на роутере и ПК. Исходная копия d2o не создавалась.
Основной роутер не изменялся. keenetic-doq оставлен работающим.

## Подготовка и проверки

- Источник диагностики: d2o 8e2c981; предпосылки c5485a7. Владелец разрешил
  перенос без недоступного REA. [Границы и отличия](../diagnostics-8e2c981.md).
- Исключения Telegram: регрессия сначала дала 8 отказов, затем прошла.
- При совмещении обработчиков работников проверка обнаружила потерю времени
  фаз D2S в наивном upstream wrapper. Отдельный задержанный вызов даёт red на
  такой версии и green на объединённой. Проверены 1500 жизненных циклов с
  выключенным и включённым учётом памяти, а также ошибки pthread_join.
- Полные локальные core/datapath/detect checks прошли. Фокусные ASan/UBSan
  и браузер с настоящим C-сервером проверяют JSON, старые отчёты, 1440 точек,
  единицы/время/PID и адаптивную вёрстку. Физическая история 24 часа не заявляется.
- OpenSSL 3.5.9 собрана из закреплённой ревизии; QEMU ARM64 выполнил
  TLS/WSS-проверки с `-UNDEBUG`. Link smoke вывел реальную версию 3.5.9.
- Полный [CI42206359660](https://github.com/shurshick/D2S/actions/runs/42206359660)
  для 1f2e55c завершён успешно: integration и engine regression proof.

## Работа диагностики на роутере

Включение через POST API с Origin панели и получение отчёта проверены.
Каталог имеет права 0700, отчёт — 0600. В 19:03 сохранён закрытый снимок;
публичная [сводка](2026-11-06-diagnostics-telegram.json) не содержит доменов/IP
из событий пользователя. Полный сырой отчёт в GitHub не публикуется.

- 301 точка, 18090 секунд фактической истории — более пяти часов.
- Кольцо: 259808 байт, отчёт: 299211 байт; ограничения 256 и 448 КиБ соблюдены.
- Шесть точек учёта памяти, именованные поля новой истории; неизвестные
  фиксированные HTTP-лимиты представлены null.
- Ошибок записи отчёта нет. Зафиксированы 448 успешных вызовов madvise,
  ошибок нет. Сумма запрошенных байтов не равна одновременной экономии RSS.
- PID датапата2977, контроллера3245, панели3682 и TG3267 сохранились после
  установки. В 19:03 RSS контроллера4572 КиБ, HWM13556 КиБ; это наблюдение
  одного стенда, не доказательство отсутствия всех утечек.
- В настоящем браузере отчёт отобразился; выбор 24 часов показал всю
  накопленную историю. Ошибок/предупреждений в консоли браузера нет.
- После проверки сбор выключен. Файлы истории удалены, download API
  возвращает enabled:false; временные копии отчёта на роутере удалены.

DoQ и его контрольные суммы не изменились. Владелец подтвердил новое видео
YouTube с перемоткой и отправку файлов Telegram/WhatsApp с выключенным
вышестоящим обходом на этом кандидате.

## Telegram Web и версия в панели

Контрольный HTTPS-запрос со стенда увеличил счётчик OUTPUT TCP443 REDIRECT
Telegram-прокси с 0 до 1. Запрос завершился curl exit28; работоспособность
Telegram Web не объявляется восстановленной. Возвращена исходная политика
исключений из общего подбора, сохранены локальный прокси и его HTTPS pass-through.

Установленную 0.3.5-test1 сначала маскировало сохранённое current:0.3.4
от прошлого обновления. Проверены настоящие версии контроллера и панели.
Регрессия UI воспроизвела ошибку; исправление использует свежую версию панели
из status API, сравнивает версии D2S и не предлагает старый stable как обновление
для более нового кандидата. История последнего обновления остаётся историей.
Исправление panel.js применено на стенде отдельно от исходного пакета кандидата;
SHA256 файла и HTTP-ответа совпали. Браузер показал d2s-v0.3.5-test1,
«Установлена тестовая сборка», кнопка отката к 0.3.4 скрыта.

## Стабильный выпуск 0.3.5

[0.3.5](https://github.com/shurshick/D2S/releases/tag/d2s-v0.3.5) опубликована
как stable/latest из `621f04bbfddc1a6fadfcde994c81c5f618738f91`.
Точный [CI42250192719](https://github.com/shurshick/D2S/actions/runs/42250192719)
прошёл с повторным использованием доказательства неизменённого ядра.
[Release42250968056](https://github.com/shurshick/D2S/actions/runs/42250968056)
собрал ARM64/ARMv7/MIPSel, выполнил 21 runtime-проверку под QEMU и три
OpenSSL link-smoke с реальной версией 3.5.9. Публичные архивы скачаны обратно;
Ed25519, SHA256, состав, требования памяти, точные заметки и шесть файлов UI
проверены. Тег после публикации не менялся.

В 19:24 МСК штатное подписанное обновление стенда завершило минутную проверку:
last_ok=true, last_release=d2s-v0.3.5, busy пустой. Движок и Telegram включены,
AUTOUPDATE=1 восстановлен (02:00–04:00), диагностика выключена и её история
удалена. Семь установленных бинарников и шесть файлов UI совпали с публичным
ARM64-пакетом. Браузер показал d2s-v0.3.5 и «Установлена последняя версия».
DoQ/резолвер/DNS-наблюдатель работают; контрольные суммы DoQ прежние.
Доступно 69320 КиБ RAM, свободно 26536 КиБ /opt.

Владелец проверял приложения на кандидате с тем же C-кодом; отдельную ручную
приёмку приложений после выпуска stable не заявляем. Промежуточная копия
D2S 0.3.4 перенесена с flash в проверенный закрытый экспорт на ПК. Исходной
копии d2o нет; она не создавалась заново. Основной роутер не изменялся.
