# Удаление прежней несовместимой ветки D2S

Эта инструкция нужна только для перехода с D2S 0.2. Для актуального D2S используйте [обычные команды удаления](../README.md#удаление).

У прежней ветки другое пространство имён и формат установки. Автоматическая миграция её настроек и изученного каталога не выполняется. Сначала сохраните нужные данные, затем запустите её собственный удалитель:

```sh
curl -fsSL https://raw.githubusercontent.com/shurshick/D2S/d2s-v0.2.0/scripts/uninstall.sh -o /tmp/d2s-remove-old.sh && sh /tmp/d2s-remove-old.sh
```

Команда полностью удаляет прежнюю установку вместе с настройками и найденными стратегиями. Затем выполните [быстрый старт](../README.md#быстрый-старт).
