D2S 0.3.1 — меньше ожиданий и повторных проверок.

- Планировщик обслуживает короткие сроки без ожидания общего трёхсекундного тика. В простое частота обслуживания сохранена.
- В диагностике и журнале видны длительности классификации, контакта и проверки плана.
- WhatsApp хранит проверку отдельно для каждой пары «имя — адрес»: новое имя не заставляет перепроверять остальные.
- Новые медиадомены из DNS запускают обработку по событию; периодический проход остаётся страховкой.
- Неудача одного медиадомена не теряет успешные результаты других. Проверка сертификата и владение собственными DNS-записями сохранены.
- Обновление с 0.3 сохраняет настройки и найденные решения. Для перехода со старой ветки 0.2 по-прежнему нужна чистая установка.

Сетевые правила, PPE, набор воздействий и таймауты проб сохранены. Полные проверки core/datapath/detect и GitHub CI пройдены. На стенде ARM64 владелец подтвердил YouTube, Telegram и WhatsApp при выключенном обходе вышестоящего шлюза. ARMv7 и MIPSel проверяются сборкой и запуском под QEMU; физических тестов этих моделей нет. Процент общего ускорения не измерен.
