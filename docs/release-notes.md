D2S 0.3.5 — новая диагностика памяти и исходные исключения Telegram.

- Перенесена диагностика t0fox/d2o 8e2c981: память TCP/QUIC/TLS объектов, каталог/HTTP/снимки, состояния работников, история на 1440 точек, счётчики возврата страниц и ошибки записи отчёта.
- Исправлено согласование байтов/КиБ, времени карточек и графиков, разделение PID и отображение отсутствующего smaps_rollup. Подозрительный рост RSS не объявляется доказанной утечкой. Старый формат истории поддерживается, полный smaps не обходится.
- Восстановлено исходное исключение telegram.org и его поддоменов из общего подбора: TCP сетей Telegram остаётся на локальном прокси. Похожие посторонние домены не исключаются. Защита от петли, помеченные пробы и HTTPS pass-through внутри прокси сохранены. Работоспособность Telegram Web этим изменением не заявляется.
- Статическая библиотека Telegram-прокси обновлена с OpenSSL 3.5.8 до исправляющего выпуска 3.5.9 той же LTS-ветки. Сам C-прокси уже содержит актуальные upstream-исправления; исходный Rust-прокси не изменился.
- Сохранены наши оптимизации этапов 1–3, включая время фаз и параллельную предварительную TCP-базу. Новые фиксированные HTTP-бюджеты из соседнего изменения донора не переносились: диагностика учитывает реальную память, не меняя прежний допуск HTTP-поисков. Отсутствующие лимиты обозначаются как null.
- Блок обновлений показывает текущую версию работающей панели вместо устаревшего current из истории обновлятора. Тестовая сборка подписана явно; старый stable не предлагается как обновление для более нового кандидата. История последней установки сохранена отдельно.

Проверки: полные core/datapath/detect checks и GitHub CI, исключения Telegram и границы DNS-имён; 1500 жизненных циклов работников; ASan/UBSan; браузер с настоящим C-сервером, 1440 точек, единицы/время/PID, старые отчёты и мобильная вёрстка. OpenSSL 3.5.9 и TLS/WSS проверены под ARM64 QEMU с включёнными assert. На стенде получено более пяти часов истории (301 точка), отчёт 299211 байт, ошибок записи нет; проверено выключение с удалением истории. Владелец подтвердил YouTube с перемоткой и отправку файлов Telegram/WhatsApp. Подробности: docs/field/2026-11-06-diagnostics-telegram.md.
