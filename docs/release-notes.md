D2S 0.5.7 — исправления Telegram из d2o 774afa6 и D2S Next.

Исправлено управление памятью: живые соединения и уже выделенные буферы учитываются отдельно от возможности принять новых клиентов. Завершённые WSS-сессии освобождают слоты; локальная нехватка ресурсов больше не помечает рабочий Cloudflare-маршрут как неисправный.

Worker теперь сохраняет точный исходный IP, порт, DC и признак медиа, включая IPv6. Прогретое соединение используется только при полном совпадении назначения. Для TCP 5222 требуется совместимый Worker с отдельным endpoint и подтверждением порта; подмена на 443 не допускается. Настройка внешнего Worker остаётся ручной.

Из D2S Next перенесено сохранение состояния шифрования ручного MTProto при параллельном выборе маршрутов. Ограничение последовательного выбора из 0.5.6 снято. Секреты и ссылки подключения сохраняются.

Добавлены диагностические счётчики ресурсов и регрессии. Панель, DNS, Wire 22, обучение и WhatsApp не менялись. Источники и границы: docs/upstream-telegram-774afa6.md. Роутеры при подготовке выпуска не использовались.
