D2S 0.5.0 — OpenWrt и точный TCP-контекст подбора.

Нативная установка OpenWrt без Entware: apk/opkg, nftables/fw4 и procd, определение LAN по DHCP/netifd. DNS-помощник WhatsApp использует отдельные hosts-файлы dnsmasq, восстанавливает свои записи при запуске и не переписывает пользовательские. DNS-логика хранится в одной библиотеке. Добавлен подписанный комплект x86_64; ARM64, ARMv7 и MIPSel сохранены.

Из t0fox/d2o c38da9f перенесены TCP-профили с Timestamp/без Timestamp, привязка поздних снимков к правильному потоку, раздельная проверка/хранение/восстановление планов и сохранение старых точных привязок при исключении семейства. Wire 22: контроллер и датапат обновляются вместе. Старый каталог читается без ручной миграции.

Наш оптимизатор учитывает TCP-профиль и сохраняет его после двух проверок. Контакт классификатора получает профиль задачи. Сохранены шесть улучшений 0.4, строгий Gateway, случайные nonce и исправление STATS. Панель отличает подтверждённый на доменах план от установки общего правила и отсутствия связи; Timestamp-профили отображаются и сопоставляются с семействами.

Проверено: полные локальные core/datapath/detect, целевые ASan/UBSan, регрессии планировщика и панели. На VM OpenWrt 25.12.6 x86_64: подписанное обновление wire21→22 с минутной проверкой, отказ изменённой подписи, независимый клиент за NAT, полный HTTPS при обоих TCP-профилях и HTTP/3 200, DNS-добавление/восстановление/точное удаление с сохранением чужих записей, удаление с сохранением конфигурации и повторная подписанная установка.

OpenWrt: нужен штатный dnsmasq с /tmp/hosts, доступные модули своего ядра и OpenSSL 3. OpenSSL 1.1.1 из OpenWrt 22.03 не подходит для подписей. Flow offloading отключается на время работы и возвращается при остановке; скорость маршрутизации может снизиться. Физические OpenWrt ARM/MIPS и отдельный IPv6-прогон пока не проверены.

В Linux выбор Timestamp кратко использует общий для namespace sysctl вокруг connect(), затем восстанавливает исходное значение. Mutex защищает собственные потоки, но не чужой одновременный SYN. Полное отсутствие влияния на другие процессы не заявляется. Общий процент ускорения не измеряли. Telegram Web и Discord voice исправленными не объявляются.

Инструкции и границы: docs/openwrt.md и docs/upstream-c38da9f.md. Подпись Ed25519 и SHA256 обязательны; ночное окно 02:00–04:00 по времени роутера.
