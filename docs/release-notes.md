D2S 0.3.2-test1 — обновлённые статусы Telegram и коробки без целей.

- Перенесена панель Telegram из t0fox/d2o 1cc424e с оформлением D2S: состояния маршрутов и DC, последние ответ и предупреждение, сворачиваемая схема.
- Готовое соединение, подтверждённый ответ Telegram и отсутствие статистики показываются отдельно. Отказ до выбора маршрута больше не подписывается как отказ прямого WSS.
- Записи с явным пустым списком целей скрыты из списка коробок и счётчика. Сохранённые планы остаются в каталоге.
- Если данные о целях не получены, панель показывает «— / цели не получены», а не ложный ноль. Ссылки семейств обновляются вместе со списком коробок.
- Сохранён порядок частично перекрывающихся карточек поиска. Кнопки управления имеют область нажатия не меньше 44 px.

Тестовый выпуск: автоматический стабильный канал остаётся на 0.3.1. Пройдены проверки панели и Telegram-прокси, браузерный сценарий с настоящим C-сервером и 16 ширинами 320–1920 px. Сетевые правила, PPE, алгоритм подбора и таймауты проб не менялись. Исправления 0.3.1 входят в комплект.

На стенде ARM64 выполнена чистая установка с резервной копией оригинала, проверены службы, правила и панель. Подтверждение работы приложений владельцем ещё ожидается. Telegram Web с ERR_CONNECTION_RESET в этот выпуск не исправлен; успех приложения Telegram не считается проверкой Web.
