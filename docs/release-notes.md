D2S 0.3.2-test2 — отдельный проход HTTPS для Telegram Web.

- TLS браузера больше не отвергается как ошибочное MTProto-приветствие. Байты идут к исходному серверу без расшифровки и подмены сертификата; проверенный MTProto по-прежнему обрабатывается первым.
- Сайты telegram.org допускаются к обычному подбору в своём протоколе. Удалено старое безусловное исключение, предполагающее наличие VPS-туннеля для всех сайтов Telegram.
- Собственные измерения и проверки плана не перенаправляются в локальный Telegram-прокси. Сохраняются их исходный сервер и TCP-кортеж; служебные метки читаются из настроек.
- HTTPS не создаёт подтверждённые ответы, отказы или охлаждения MTProto. Его активные подключения учитываются отдельно.
- Из test1 сохранены новые статусы и схема Telegram, скрытие действительно пустых коробок без удаления планов, корректный счётчик при неполных данных и порядок карточек поиска.

Локально пройдены проверки Telegram и ASan/UBSan, регрессия допуска HTTPS и модель правил iptables/nftables, включая IPv6, изменение меток, восстановление и сохранность чужих правил. LAN-перехват, диапазоны адресов, PPE, DNS и keenetic-doq не менялись.

Тестовый выпуск: стабильный канал остаётся на 0.3.1. Полная регрессия и проверка Telegram Web на стенде ещё выполняются; успех сайта у владельца пока не заявляется. Ранее на test1 владелец подтвердил YouTube с перемоткой, приложение Telegram и WhatsApp при выключенном основном движке верхнего шлюза. Для проверки Web отдельно выключен и верхний Telegram-туннель.
