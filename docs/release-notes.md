D2S 0.5.2 — исправления запуска WhatsApp и обучения семейств для YouTube.

WhatsApp: исправлен выбор подтверждённого плана для ECH-соединений с разными TCP Timestamp-профилями. Ранее часть таких соединений не получала подходящий план, из-за чего приложение могло зависать на подключении или загружаться без оформления. Исправлены выбор по имени, адресу и временному пробному плану; несовместимые профили по-прежнему разделены. На основном Keenetic проверены три холодных запуска приложения с нормальной загрузкой чатов и оформления.

YouTube и обучение: устранена автоматическая постоянная заморозка обучения при заполнении журнала из 256 наблюдений. Новые подтверждения теперь могут заменять старые неопределённые или обычные положительные записи. Отрицательные данные и исключения сохраняются, лимит памяти не увеличен. Старая заморозка снимается при загрузке, если есть безопасно заменяемое место. На основном роутере подтверждён приём новых результатов, сохранены все 227 отрицательных записей и 61 прежний идентификатор плана. Пользователь подтвердил заметное улучшение старта и перемотки YouTube. Это не гарантия устранения всех задержек у любого провайдера.

Дополнительно: добавлена ручная ограниченная диагностика d2sfetch --compare-http для сравнения прежнего и браузероподобного HTTP-запросов. Она не имитирует полный отпечаток Chrome и не меняет правила подтверждения стратегий. Проведены измерения поиска планов; усложняющий индекс не включён, поскольку устойчивый выигрыш не подтвердился.

Регрессионные тесты, ASan/UBSan и сборки для ARM64, ARMv7, MIPSel, MIPS BE и amd64 прошли. Подписанные установочные комплекты выпускаются для ARM64, ARMv7, MIPSel и x86_64. Keenetic/Entware и OpenWrt сохранены. Wire Protocol 22, настройки, каталог и идентификаторы подтверждённых планов сохраняются; обновляется весь комплект компонентов.
