## Исправления

Admission учитывает уже живых клиентов отдельно от бюджета дополнительных.
При пересмотре бюджета сохраняются выделенные буферы, отдельно ограничивается
их дальнейший рост и общий потолок. Завершившиеся WSS-сессии освобождают слот
после close deadline. Локальная нехватка памяти не охлаждает рабочие CF-маршруты.

Worker сохраняет исходные IP, порт, DC/media, включая IPv6. Прогретое соединение
принимается только при совпадении полного hostname/path; таблица прогрева больше
не подменяет реальный адрес назначения. 443 использует /apiws, 5222 — отдельный
/d2o/apiws/5222. Wire-имена d2o сохранены для совместимости внешнего Worker.
Дополнительно к адаптации Next запрос 5222 требует подтверждения WebSocket
subprotocol d2o-tcp-5222-v1: старый Worker без подтверждения отклоняется,
вместо молчаливой подмены порта на 443. Внешний Worker автоматически не создаётся.

## Ручной MTProto

Перенесено исправление Next 756595da58942e6b2bf5f1c40ebb5f7acd45b8d6:
четыре cipher context клонируются кандидатам и передаются от победителя,
проигравшие освобождаются. Ограничение последовательного выбора из 0.5.6 снято.
Регрессии проверяют несколько пакетов в обоих направлениях после выбора
маршрута, последовательный и параллельный режимы секретного MTProto.

## Проверки

Перенесены fixture exact-target (IP/media/DC/порт/hostname), IPv6, сохранения
буферов без headroom, отказа admission и освобождения terminal слотов.
Нагрузочная фикстура D2S сохранена с четырьмя CF Proxy потоками, включая два
медиа; Worker отдельно проверяется raw-stream тестами. Дополнительная регрессия
WebSocket требует точный subprotocol для 5222 и отклоняет отсутствие/binary.
Локальные тесты/эмуляция не подменяют проверку приложений на реальном роутере.
