# Диагностика d2o 8e2c981 и возврат исключений Telegram

Источник: [t0fox/d2o 8e2c98146cf0b712dc967fbec558c7b904666e87](https://github.com/t0fox/d2o/commit/8e2c98146cf0b712dc967fbec558c7b904666e87).
Перенос включает диагностические предпосылки из c5485a7. Backend сравнивался
с fd4e262, интерфейс — с уже интегрированным 1cc424e и текущим D2S 0.3.4.
Владелец явно разрешил выполнить этот перенос без недоступного REA. Запись
ручного анализа: `D2S-DIAG-8e2c981-20261106`; это не Evidence, созданный REA.

## Границы переноса

- Учёт выбранных TCP/QUIC/TLS выделений, пиков, числа объектов и отказов;
  объёмы каталога, HTTP-хранилища и сохранённых снимков; состояние работников.
- Именованные поля истории, точные байты, согласование карточек со временем
  графика, разделение поколений PID, нейтральный unsupported для отсутствующего
  необязательного smaps_rollup, ошибки записи JSON и счётчики madvise.
- Формат истории остаётся совместимым со старыми позиционными строками.
  Новая история имеет 1440 точек; кольцо D2S занимает 259808 байт, менее 256 КиБ.
  Предел JSON поднят до 448 КиБ. Весь smaps не обходится.
- Новые фиксированные ограничения HTTP-хранилища из соседнего изменения
  c5485a7 не перенесены: они меняли бы допуск HTTP-поисков. D2S считает реальные
  выделенные массивы/очередь/сведения об отказах, сохраняя существующую политику.
  При отсутствии заданных лимитов `http_storage_limits` — null, а не выдуманный
  нулевой предел. Это намеренное отличие от донора.
- Оптимизации этапов 1–3 сохранены: ресурсная выборка, ближайшие сроки,
  накопление classify/contact/verify_ms, достаточный положительный ответ,
  параллельная предварительная TCP-база. Классификатор detect не переписывается.

## Reviewed engine changes

- `core/catalog.c`, `include/d2s_catalog.h`: логический объём живого каталога.
- `core/diagnostics.c`, `include/d2s_diagnostics.h`: сбор, компактная история,
  атомарные счётчики шести точек выделения, сериализация и доступность procfs.
- `core/d2sc.c`: включение учёта вместе с диагностикой и учёт ошибок записи.
- `core/sched.c`, `include/d2s_sched.h`: состояния/время работников, результаты
  pthread_join и защита ещё занятой ячейки, размеры снимков, madvise, возврат
  исходного исключения telegram.org. Длительность фаз D2S сохранена отдельно.
- `core/httpsearch.c`: только счётчики фактической памяти и отказов выделения,
  без новых бюджетов или изменения выбора кандидатов.
- `core/tls12.c`, `tls13.c`, `quicconn.c`, `quicprobe.c`, `verify.c`: учёт
  владения существующими объектами; размеры, TLS/QUIC вердикты и байты не меняются.
- Регрессии каталога, JSON, runtime и работников; подключение diagnostics.o
  ко всем нужным тестам и бинарникам. Пинованные хеши сохранены в
  tests/keenetic/audited-engine-changes.json; новые тесты проверяются CI.

## Telegram

Восстановлено исходное исключение telegram.org и его поддоменов из общего
подбора с проверкой границы DNS-метки и регистра. Похожие посторонние имена
остаются допустимыми целями. Маршрутизация TCP сетей Telegram через локальный
прокси, защита от петли и исключения собственных помеченных проб сохранены.
Существующий безопасный HTTPS pass-through внутри локального прокси сохранён;
это не означает работоспособность Telegram Web через MTProto/WSS.

Последние изменения C-прокси d2o — TG_ROUTE_NONE и исправленный порог теста
переподключения — уже находятся в D2S. Это не новый рабочий таймаут.
Исходный Rust-прокси t0fox/z2kOW не изменился относительно проверенной 9fc14bb:
src tree `275cbc5e58d7bb7fd6983a7d61e831234942348d`, tests tree
`ce83e3b33f8fb443ac862f72c5ba584e5ea65eea`.

Обновлена статическая библиотека Telegram-прокси: OpenSSL 3.5.8 → 3.5.9,
закреплённый commit `45e844fa2a14ec92d146bd8f5778ac130b6625fb`.
Это исправляющий выпуск той же LTS-ветки, [официальные изменения](https://openssl-library.org/news/openssl-3.5-notes/).
Системные библиотеки Entware и keenetic-doq не обновляются этим изменением.

## Проверки

Регрессия исключений сначала дала восемь отказов, после возврата правила
прошла. Отдельная регрессия обнаружила потерю времени фаз при наивном переносе
upstream worker_run; объединённый обработчик сохраняет время задержанного
вызова и новые состояния работников. Проверены 1500 созданий/завершений.
Фокусные C/JSON/HTTP проверки и ASan/UBSan пройдены; браузер с настоящим
C-сервером проверяет 1440 точек, единицы, время/PID, старый формат и procfs.
Полные локальные проверки и CI пройдены; полевой результат и публикация
зафиксированы в отчёте ниже.

Полный CI исходного 1f2e55c прошёл. [Полевая проверка](field/2026-11-06-diagnostics-telegram.md)
содержит более пяти часов фактической истории, проверку удаления отчёта,
приёмку приложений владельцем и исправление устаревшей версии в блоке обновлений.
Стабильная 0.3.5 из 621f04b опубликована для трёх архитектур и установлена
штатным подписанным обновлятором стенда. Установленные бинарники и UI сверены
с публичным архивом; диагностика выключена, AUTOUPDATE=1 восстановлен.
